# 🧩 7 Days of HTML Practice

This repository contains my **7-day HTML practice plan**, focused on building strong frontend fundamentals through **daily hands-on exercises**.

Each day covers a specific HTML topic with **simple explanations, examples, and mini practice tasks** to reinforce learning.

---

## 📌 What This Repository Covers

- Core HTML structure and syntax  
- Text formatting and semantics  
- Lists, links, and images  
- Semantic HTML and tables  
- Forms and user input  
- Accessibility and best practices  

This project is part of my **frontend learning journey** and is designed for consistent daily progress.

---

## 📅 Day 1 – Basic HTML Syntax

### 📘 Topics Covered
- What is HTML  
- Structure of an HTML document  
- `<!DOCTYPE html>`  
- `<html>`, `<head>`, `<title>`, `<body>`  
- Basic tags: `<h1>` to `<h6>`, `<p>`, `<br>`, `<hr>`  
- HTML comments  

### 🛠 Practice Tasks
- Create a basic HTML page  
- Add headings and paragraphs  
- Use line breaks and horizontal rules  
- Add comments in HTML  

### 🎯 Goal  
Understand the basic structure of an HTML page and become comfortable writing simple HTML code.

---

## 📅 Day 2 – Meta & Text Basics

### 📘 Topics Covered
- `<meta>` tags (charset, viewport, description)  
- Page title optimization  
- Text formatting tags: `<strong>`, `<em>`, `<b>`, `<i>`  
- `<span>` vs `<p>`  
- HTML entities  

### 🛠 Practice Tasks
- Add meta tags for charset and viewport  
- Format text using semantic and non-semantic tags  
- Use inline and block-level text elements  
- Practice HTML entities for special characters  

### 🎯 Goal  
Learn how to properly structure page metadata and format text content using HTML best practices.

---

## 📅 Day 3 – Text Basics & Lists

### 📘 Topics Covered
- Text semantics and meaning in HTML  
- `<abbr>` for abbreviations  
- `<address>` for contact and author information  
- HTML Lists:  
  - Ordered lists (`<ol>`)  
  - Unordered lists (`<ul>`)  
  - Description lists (`<dl>`, `<dt>`, `<dd>`)  

### 🛠 Practice Tasks
- Use `<abbr>` and `<address>` tags in a sample webpage  
- Create ordered, unordered, and description lists  
- Build a combined mini portfolio page using all topics learned so far  

### 🎯 Goal  
Develop clarity in text semantics and list structures, and apply all learned HTML concepts in a single structured page.

---

## 📅 Day 4 – Links & Images

### 📘 Topics Covered

**HTML Links**
- Relative links  
- Absolute links  
- Internal links using section IDs  
- Navigation bar using `<nav>`  
- Download links  
- Email (`mailto:`) links  
- Phone (`tel:`) links  
- `target="_blank"` usage  

**HTML Images**
- `<img>` tag with width, height, title, and loading attributes  
- `<figure>` and `<figcaption>`  
- Simple image gallery layout  

### 🛠 Practice Tasks
- Create a webpage demonstrating all types of HTML links  
- Add images using `<img>`, `<figure>`, and `<figcaption>`  
- Build a beginner-friendly portfolio page combining:
  - Page navigation  
  - Multiple link types  
  - Images and an image gallery  
  - Clean semantic structure  

### 🎯 Goal  
Understand how navigation and images work together to create structured, user-friendly web pages.

---

## 📅 Day 5 – Semantic HTML & Tables

### 📘 Topics Covered

**Semantic HTML Elements**
- `<header>`  
- `<nav>`  
- `<main>`  
- `<section>`  
- `<article>`  
- `<aside>`  
- `<footer>`  

**Why Semantic HTML**
- Accessibility benefits  
- SEO improvements  
- Better page structure  

**HTML Tables**
- `<table>`  
- `<tr>`, `<th>`, `<td>`  
- `<thead>`, `<tbody>`, `<tfoot>`  
- `colspan` and `rowspan`  
- `<caption>`  

### 🛠 Practice Tasks
- Build a webpage layout using only semantic elements  
- Create a student marks table with:
  - Header row  
  - Multiple data rows  
  - Table caption  
- Use colspan and rowspan in a timetable or report-style table  
- Combine semantic layout + table into one mini project page  

### 🎯 Goal  
Understand how semantic HTML improves page structure, readability, and accessibility, and learn how to display structured data effectively using HTML tables.

---

## 📅 Day 6 – HTML Forms

### 📘 Topics Covered

- What are HTML forms and why they are used  
- `<form>` element and attributes:
  - `action`  
  - `method` (GET vs POST)  

**Form Input Types**
- `<input type="text">`  
- `<input type="email">`  
- `<input type="password">`  
- `<input type="number">`  
- `<input type="radio">`  
- `<input type="checkbox">`  
- `<input type="date">`  
- `<input type="file">`  
- `<input type="submit">`  
- `<input type="reset">`  

**Other Form Elements**
- `<label>` (accessibility)  
- `<textarea>`  
- `<select>`, `<option>`, `<optgroup>`  
- `<datalist>`  
- `<fieldset>` and `<legend>`  

**Form Attributes**
- `placeholder`  
- `required`  
- `readonly`  
- `disabled`  
- `name`  
- `value`  

### 🛠 Practice Tasks
Create a simple contact form with:
1. `<form>` tag  
2. Labels + input fields  
3. Select dropdown  
4. Datalist  
5. Fieldset + legend  
6. Textarea  
7. Buttons (submit + reset)  

### 🎯 Goal  
Learn how to collect user input using HTML forms, understand different input types and attributes, and build accessible, well-structured forms for real-world websites.
